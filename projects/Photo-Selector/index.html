Desktop App

Photo Selector

SD 카드를 연결하면 AI가 중복되거나 초점이 나간 사진을 자동으로 분류합니다.
추천 사진을 골라 한 번에 복사하거나 이동하세요.

Mac App Store Windows 다운로드

Features

AI로 똑똑하게 사진 정리

중복 사진 분류

유사한 사진들을 자동으로 그룹화하고, 가장 선명한 한 장을 추천합니다.

초점/흔들림 감지

초점이 나가거나 흔들린 사진을 자동으로 태깅하여 쉽게 걸러냅니다.

스마트 추천

AI가 촬영 정보와 화질을 분석해 최적의 사진을 추천합니다.

빠른 복사·이동

추천 사진을 한 번에 선택해 원하는 폴리더로 복사하거나 이동합니다.

Workflow

이렇게 사용하세요

1

SD 카드 연결

카메라의 SD 카드를 컴퓨터에 연결합니다.

2

AI 자동 분류

앱이 자동으로 중복·흔들림 사진을 분류합니다.

3

추천 확인

AI가 추천한 최적의 사진을 확인합니다.

4

복사·이동 완료

원하는 폴리더로 사진을 복사하거나 이동합니다.
