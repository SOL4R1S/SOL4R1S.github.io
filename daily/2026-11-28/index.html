구글 ABFS가 겨냥한 병목은 코드 생성보다 저장소와 빌드예요

구글이 대규모 Git 저장소 작업을 가속하는 오픈소스 프레임워크 ABFS를 공개했다고 보도됐어요. 자체 실험에서는 안드로이드 소스 체크아웃을 약 36분에서 8초 미만으로, 전체 빌드를 약 80분에서 2분여로 줄였다고 해요.

자세히 보기
  • 안드로이드 17 오픈소스 프로젝트(AOSP)는 1,084개 Git 저장소와 약 162만 개 파일로 구성돼요.
  • 보도된 수치는 구글 자체 실험 결과예요.
  • CI와 개발자 작업공간 사이에서 기존 빌드 결과를 재사용하는 공유 캐시가 포함돼요.
얻는 것

지금 할 일
인공지능신문 기사에서 ABFS의 공유 캐시 설명을 읽고, 팀 CI에서 체크아웃과 빌드 시간을 따로 측정해 보세요.
왜 지금
